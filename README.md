# Budget Buddy (Android)

Budget Buddy is an Android app (Jetpack Compose) for managing personal budgets and shopping planning.

## Features

- **Monthly budgeting**: Enter monthly income and expenditure, then see estimated balance.
- **Nearby store specials**: View a list of closest stores and their current specials.
- **Weekly / monthly shopping baskets**:
  - Add products with estimated prices.
  - Switch between weekly and monthly baskets.
  - Mark items as bought.
  - Edit prices when real prices differ.
  - View total estimated expenditure per basket.

## Build

1. Install Android Studio (Koala or newer) with Android SDK 34.
2. Open this folder in Android Studio.
3. Run the `app` configuration on an Android emulator or device.

> Note: In this environment, Android SDK is unavailable so CI-style Gradle Android builds may fail.
